# Event-handling

## Описание проекта

Event-handling — это интерактивное веб-приложение с галереей случайных изображений. Проект демонстрирует работу с DOM и обработчиками событий JavaScript, а также разделение HTML, CSS и JavaScript по отдельным файлам.

## Возможности приложения

- Просмотр случайных изображений в галерее.
- Обновление всех изображений без перезагрузки страницы.
- Добавление новых изображений.
- Удаление последнего изображения. Если в галерее осталась одна картинка, кнопка удаления становится неактивной.
- Полноэкранный просмотр изображения по клику.
- Закрытие полноэкранного просмотра кнопкой, нажатием клавиши Escape или кликом по затемнённому фону.
- Открытие изображения с клавиатуры с помощью Enter или Space.

## Структура проекта

- `index.html` — разметка страницы.
- `index.css` — стили галереи и полноэкранного просмотра.
- `index.js` — логика приложения и обработчики событий.

## Как запустить проект

### В CodeSandbox

1. Откройте [CodeSandbox](https://codesandbox.io/).
2. Импортируйте репозиторий GitHub: `https://github.com/Liachim707/Event-handling`.
3. Дождитесь загрузки проекта.
4. Откройте Preview, чтобы просмотреть и проверить приложение.

### Локально на компьютере

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта в терминале.
3. Установите зависимости:

   ```bash
   npm install
   ```

4. Запустите локальный сервер:

   ```bash
   npm start
   ```

5. Откройте в браузере адрес, указанный в терминале.
